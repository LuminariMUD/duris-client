# Support

Start with the [installation instructions and troubleshooting guide](README.md#install). Use Mudlet **4.19.1 or newer** and enable **GMCP** in both your profile and the game.

- **Package bugs and feature requests:** use the [issue forms](https://github.com/LuminariMUD/duris-client/issues/new/choose).
- **Setup and usage questions:** open an [issue](https://github.com/LuminariMUD/duris-client/issues/new) with your package version, Mudlet version, operating system, and what you have already tried.
- **Security concerns:** use the private reporting channel in [SECURITY.md](SECURITY.md).
- **New Duris game information:** visit [New Duris](https://www.newduris.com/).
- **Mudlet documentation:** see the [Mudlet manual](https://wiki.mudlet.org/w/Manual:Contents).

Useful diagnostics include `ui debug`, `mapper status`, and `mapper debug`. Remove credentials, saved login commands, character details you do not want public, and private chat before posting logs or screenshots. Do not attach your full Mudlet profile or saved `arjauto.json` file.

This repository supports the New Duris package. Reference documents copied from LuminariGUI describe a different client and may not apply here.
